# Learning archive

My early programming practice, 2017-2019. Small exercises and experiments, kept as they were, with their original commits and dates, as a record of the learning journey.

If you're just starting out: this is what the beginning looks like. Keep building.

## C

1. **[name-initials](c/name-initials)** (2017). Prints a name's initials ("abdur rakib" → "AR") from a command-line argument. Learned: strings, `argv`.
2. **[recursion-fibonacci](c/recursion-fibonacci)** (2017). Prints the Fibonacci series using recursion. Learned: recursive functions.
3. **[algorithm-practice](c/algorithm-practice)** (2019). Linear search, binary search, bubble sort and selection sort, made alongside YouTube tutorials. Learned: basic searching and sorting.

## JavaScript

4. **[js-practice](js/js-practice)** (2017). Practice files from LinkedIn Learning's JavaScript Essential Training: objects, functions, dates and data. Learned: core JavaScript.
5. **[funjs](js/funjs)** (2018). Changes a heading's colour from a text input. Learned: DOM selection and event listeners.
6. **[bookmarker-js](js/bookmarker-js)** (2019). A bookmark manager that saves sites in the browser. Learned: plain JavaScript with localStorage.

## CSS

7. **[youtube-type-logo-animation](css/youtube-type-logo-animation)** (2017). A logo animation in the style of a YouTube intro. Learned: CSS animation.

## Node.js

8. **[live-chat-websocket](node/live-chat-websocket)** (2019). A live chat app. Learned: WebSockets with Node.
9. **[express-react](node/express-react)** (2019). A boilerplate pairing a React front end with an Express API. Learned: connecting a client to a Node backend.

## DevOps

10. **[travis-ci-docker](devops/travis-ci-docker)** (2019). A small Express server with a Dockerfile and Travis CI config. Learned: containerising a Node app and basic CI.

## Web

11. **[esho-shikhi-app-landing](web/esho-shikhi-app-landing)** (2019). A static landing page for the Esho Shikhi learning app. Learned: Sass and responsive layout.
